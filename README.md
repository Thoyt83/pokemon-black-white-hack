# Pokémon Black & White: Vanilla+

A paired Pokémon Black and Pokémon White ROM-hack project focused on a fair,
modernized version of the original Unova adventure.

The goal is a modest difficulty increase through better trainer composition,
better moves and items, and careful progression—not inflated levels, competitive
gimmicks, or a pre-game National Dex.

## Current status

Planning and toolchain setup. The first implementation milestone is a shared
trainer rebalance for both English Black and English White.

See [docs/DESIGN.md](docs/DESIGN.md) for the design rules and proposed first
changes, [docs/IDEAS.md](docs/IDEAS.md) for the feature backlog, and
[docs/ROM_SETUP.md](docs/ROM_SETUP.md) for local ROM setup.

## Repository policy

This repository contains only original configuration, scripts, documentation,
and distributable patch files. Commercial ROM images, save files, extracted ROM
contents, and rebuilt game binaries are intentionally excluded.
